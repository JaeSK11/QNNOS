══════════════════════════════════════════════════════════════════════════════════════
 MEASUREMENT SCHEME
══════════════════════════════════════════════════════════════════════════════════════

     Each qubit is measured on 3 Pauli bases, yielding its full Bloch vector:

     Qubit i → ⟨Zᵢ⟩, ⟨Xᵢ⟩, ⟨Yᵢ⟩

     Output vector (60 elements):
     ┌──────────────────────┬──────────────────────┬──────────────────────┐
     │  ⟨Z₀⟩ ⟨Z₁⟩ ... ⟨Z₁₉⟩ │  ⟨X₀⟩ ⟨X₁⟩ ... ⟨X₁₉⟩ │  ⟨Y₀⟩ ⟨Y₁⟩ ... ⟨Y₁₉⟩ │
     │     indices 0–19     │     indices 20–39    │     indices 40–59    │
     └──────────────────────┴──────────────────────┴──────────────────────┘

     Each ⟨·⟩ ∈ [-1, +1]

     Bloch sphere interpretation per qubit:
            ⟨Z⟩ = cos(θ)              (population)
            ⟨X⟩ = sin(θ)cos(φ)        (real coherence)
            ⟨Y⟩ = sin(θ)sin(φ)        (imaginary coherence)
